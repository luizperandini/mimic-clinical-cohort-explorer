# MIMIC Clinical Cohort Explorer

## Overview

This project demonstrates how to build reproducible clinical cohorts from the MIMIC-IV database using PostgreSQL, Python, and SQL.

The goal is to simulate real-world healthcare analytics workflows commonly used in:

- Real-World Data (RWD)
- Clinical Research
- Healthcare AI
- Clinical Data Management
- Clinical Informatics

---

## Project Objectives

- Import MIMIC-IV data into PostgreSQL
- Explore the healthcare data model
- Build reusable clinical cohorts
- Perform SQL-based healthcare analytics
- Develop reusable Python utilities
- Document the complete workflow

---

## Technologies

- Python
- PostgreSQL
- SQLAlchemy
- Pandas
- SQL
- Jupyter Notebook

---

## Dataset

This project uses the publicly available **MIMIC-IV Demo** dataset.

The dataset is **not included** in this repository.

It can be downloaded from PhysioNet.
